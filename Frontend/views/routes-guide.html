🔐 Authentication Routes

Auth Routes (/api/auth)
  • POST/register - Register new user
  • POST/login - Login user
  • POST/logout - Logout user
  • GET/me - Get current user
  • POST/send-otp - Send OTP
  • POST/verify-otp - Verify OTP
Login Routes (/api/login)
  • POST/authenticate - Authenticate user
  • GET/session - Get session info
Account Routes (/api/account)
  • GET/profile - Get user profile
  • PUT/profile - Update profile
  • POST/change-password - Change password

⚙️ Compiler & Code Execution Routes

Compiler Routes (/api/compiler)

  • GET/languages - Get supported languages
Code Engine Routes (/api/code-engine)
  • POST/execute - Execute with engine
  • GET/status - Get execution status

Editor Routes (/api/editor)
