# VulkanKT - Machine Code Compiler API Documentation

## Overview

**VulkanKT** is a high-performance machine code compiler engine integrated into the Xenithra Compiler. It translates source code into machine code through a multi-stage compilation pipeline: Code Translation → Assembly Generation → Optimization → Machine Code Compilation.

**Version:** 1.0.0  
**Base URL:** `http://localhost:8000/api/vulkan`

---

## Features

✅ **Multi-Language Support:** C, C++, Java, Python, JavaScript, Rust, Go  
✅ **Multiple Architectures:** x86, x64, ARM, ARM64, MIPS  
✅ **Optimization Levels:** 0-3 (includes dead code removal, peephole optimization, function inlining, vectorization)  
✅ **Intermediate Representation:** Full IR output for analysis  
✅ **Assembly Code Generation:** x86/x64, ARM, MIPS assembly output  
✅ **Code Analysis:** Syntax validation and AST parsing without compilation  
✅ **User Activity Tracking:** Automatic logging for authenticated users

## API Endpoints

### 1. Compile Source Code to Machine Code

**Endpoint:** `POST /api/vulkan/compile`

**Authentication:** Optional (using JWT token)

**Request Body:**
```json
{
  "code": "int main() { printf(\"Hello World\"); return 0; }",
  "language": "c",
  "target": "x64",
  "flags": {
    "optimization": 2
  }
}
```

**Parameters:**
| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `code` | string | ✅ Yes | — | Source code to compile |
| `language` | string | ✅ Yes | — | `c`, `cpp`, `java`, `python`, `javascript`, `rust`, `go` |
| `target` | string | ❌ No | `x64` | `x86`, `x64`, `arm`, `arm64`, `mips` |
| `flags.optimization` | number | ❌ No | `2` | Optimization level: 0, 1, 2, 3 |

**Success Response (200):**
```json
{
  "success": true,
  "message": "Compilation successful",
  "data": {
    "machineCode": "554889e54883ec2048bf0000000000e8...",
    "assembly": "; Assembly Generated by VulkanKT\n...",
    "ir": {
      "version": "1.0",
      "language": "c",
      "target": "x64",
      "metadata": {
        "functions": 1,
        "variables": 0,
        "imports": 0
      },
      "code": { ... }
    },
    "metadata": {
      "language": "c",
      "target": "x64",
      "size": 8192,
      "compressed": false,
      "optimizationLevel": 2
    },
    "executablePath": "/path/to/compiled/binary",
    "hexDump": "00000000: 55 48 89 e5 48 83 ec 20 48 bf 00 00 00 00 00 00"
  }
}
```

**Error Response (400/500):**
```json
{
  "success": false,
  "error": "Unsupported language: kotlin",
  "stage": "translation"
}
```

## Usage Examples

### Example 1: Compile C Code to x64 Machine Code

```bash
curl -X POST http://localhost:8000/api/vulkan/compile \
  -H "Content-Type: application/json" \
  -d '{
    "code": "#include <stdio.h>\nint main() {\n  printf(\"Hello, World!\");\n  return 0;\n}",
    "language": "c",
    "target": "x64",
    "flags": { "optimization": 3 }
  }'
```

### Example 2: JavaScript Fetch Request

```javascript
const response = await fetch('http://localhost:8000/api/vulkan/compile', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_JWT_TOKEN' // Optional
  },
  body: JSON.stringify({
    code: 'int main() { return 42; }',
    language: 'c',
    target: 'x64',
    flags: { optimization: 2 }
  })
});

const result = await response.json();
console.log('Machine Code:', result.data.machineCode);
console.log('Assembly:', result.data.assembly);
```

### Example 3: Analyze Code First

```javascript
// Analyze without compilation
const analysis = await fetch('http://localhost:8000/api/vulkan/analyze', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    code: 'void test() { int x = 5; }',
    language: 'c'
  })
});

const result = await analysis.json();
console.log(`Functions: ${result.data.stats.functions}`);
console.log(`Variables: ${result.data.stats.variables}`);
```

## Compilation Pipeline

```
Source Code
    ↓
[1] CODE TRANSLATION (CodeTranslator)
    └─ Parse → Extract AST → Convert to IR
    ↓
[2] ASSEMBLY GENERATION (AssemblyGenerator)
    └─ Generate target-specific assembly (x86/x64/ARM/MIPS)
    ↓
[3] OPTIMIZATION (Optimizer)
    └─ Dead code removal
    └─ Peephole optimization
    └─ Function inlining
    └─ Vectorization (level 3)
    ↓
[4] MACHINE CODE COMPILATION (MachineCodeCompiler)
    └─ Compile to binary
    └─ Generate hex dump
    └─ Output executable
    ↓
Machine Code (Binary/Executable)
```

---

## Optimization Levels

| Level | Features | Use Case |
|-------|----------|----------|
| **0** | None | Debugging (maximum symbol info) |
| **1** | Dead code removal | Fast compilation |
| **2** | Dead code + peephole + inlining | **Default** - balanced |
| **3** | All + vectorization | Maximum performance |

---

## Error Codes

| Code | Status | Meaning |
|------|--------|---------|
| 400 | Bad Request | Invalid input (missing code/language, code too large) |
| 500 | Server Error | Compilation/translation failed |

---

## Limits

- **Max Code Size:** 10 MB
- **Compilation Timeout:** 30 seconds
- **Output Limit:** First 20 lines of hex dump returned

## Integration with Existing Compiler

VulkanKT works alongside the existing compiler:

- **`/api/compiler`** - GDB-based C/C++ compiler
- **`/api/vulkan`** - VulkanKT machine code compiler
- **`/api/code-engine`** - Code execution engine

## Architecture Support

### x64 (Default)
```assembly
push rbp
mov rbp, rsp
sub rsp, 32
```

### x86
```assembly
push ebp
mov ebp, esp
sub esp, 32
```

### ARM
```assembly
push {fp, lr}
add fp, sp, #4
```

---

## Output Formats

1. **Machine Code (Hex)** - Hexadecimal string representation
2. **Assembly Code** - Target-specific assembly language
3. **Intermediate Representation** - Language/target-independent IR
4. **Hex Dump** - Human-readable binary format with ASCII
